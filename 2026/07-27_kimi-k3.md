# Kimi K3: Open Frontier Intelligence

* Authors: Kimi
* Link: https://github.com/MoonshotAI/Kimi-K3/blob/main/k3_tech_report.pdf
* Date: 2026-07-27

## Notes

* 2.8T parameter MoE, 104 billion active, native vision capabilities, 1-million-token context window
* Kimi Delta Attention, Gated MLA (Gated Multi-head Latent Attention), Attention Residuals, Stable LatentMoE
* model architecture scales information flow along three dimensions: sequence length, network depth, and model width:
    * sequence: Hybrid Attention combines three KDA layers with one Gated MLA layer in each block
    * depth: AttnRes enable each module to selectively retrieve representations from the embedding, the current block,
      and preceding blocks
    * width: each attention layer is followed by a Stable LatentMoE layer that performs sparse channel mixing,
      effectively activating 16 of 896 routed experts for each token
* KDA: Gated DeltaNet but using a diagonal matrix so each feature dimension has its own forget gate; chunkwise parallel
* Gated MLA: No Position Encoding (NoPE), rely on KDAs for position-sensitive and recency-aware sequence mixing; per
  channel and per token output gates
* AttnRes: each layer selectively retrieves representations from all preceding layers rather than accumulating them
  uniformly; divide layers into 8 blocks to reduce overhead
* Stable LatentMoE: RMSNorm before the up-projection and Sigmoid Tanh Unit GLU (SiTU-GLU) to suppress activation
  explosion, and Quantile Balancing (QB) for load balancing
* Quantile Balancing: adjusts expert biases from router-score quantiles so each expert receives a fair share of tokens
  without auxiliary losses or heuristics
* native vision: MoonViT-V2 encodes images and videos, and a lightweight projector maps the resulting visual features
  into the shared embedding space before backbone processing; jointly trained from scratch
* per-head Muon: instead of applying Newton–Schulz orthogonalization to the full Q, K, and V projection matrices,
  partition their momentum matrices along the head dimension and orthogonalize each head’s block separately
* context window grows from 8K to 64K tokens during pre-training, and from 256K to 1M tokens during the cooldown phase
* SFT stage establishes a high-quality cold-start policy for the subsequent RL stage
* RL across three domains: general tasks, general agents, coding agents; three reasoning effort levels in {low, high,
  max}
* Multi-Teacher On-Policy Distillation (MOPD) to consolidate domain-specialized capabilities across reasoning efforts
  into a unified model
* quantization-aware training (QAT) from the SFT stage onward, with MXFP4 weights and MXFP8 activations
* pre-trained with a multi-token-prediction (MTP) layer that mirrors the structure of a backbone block; fine-tune the
  pre-trained MTP layer into an EAGLE-3-style draft model
* unified white-box RL environment that represents an agent harness as a collection of configurable, composable modules,
  including tool interfaces, system prompts, context management strategies, skills, memories, subagents, and other
  components
* chunkwise kernel for training and prefill: FlashKDA, a CUTLASS-based chunkwise kernel that overlaps intra-chunk
  computation with cross-chunk state propagation
* intra-device context parallelism for long-context prefill: automatic SM-level context-parallel (CP)
  planner partitions the sequence across the SMs of a single rank, evaluates the segment transitions in parallel, and
  merges them to recover each segment’s exact initial state
* KDA Context Parallelism (KCP): decomposes the effect of each segment into two locally computable quantities, a
  cumulative transition acting on the incoming state and a state generated locally from zero
* perfectly balanced expert-parallel MoE training:  MoonEP, preserves the overall computation flow of conventional
  schemes such as DeepEP and additionally introduces online planning and migration of redundant experts. In the forward
  pass, plan the redundant experts from the router outputs of the current micro-batch and layer and prefetch them before
  the routed expert computation. In the backward pass, stage their gradients in a local reduce buffer and, once the
  computation completes, reduce them back to the gradient buffers of their home ranks
* memory-efficient training: unified storage abstraction for activations; memory-efficient MoE; memory-efficient
  AttnRes; remotely offload activations to the memory of other PP ranks using the Mooncake Transfer Engine; Pipeline
  ZeRO-2 gradient sharding to shard gradients across data-parallel (DP) ranks, store the sharded gradients in CPU
  memory; P2P-based Muon orthogonalization: each rank retrieves only the shards of its locally owned parameters via
  peer-to-peer (P2P) communication with the corresponding owner ranks
* multimodal encoder optimization: dynamic CP in multimodal encoder - a single large image is partitioned along the
  patch dimension across multiple devices, and attention is computed by gathering key–value pairs (gather-KV) across CP
  ranks; encoder computation in PP bubbles - ViT forward passes of the first PP micro-batches are executed synchronously
  upfront, the remaining forward passes are scheduled into pipeline bubbles, and the backward passes are handled
  analogously
* agentic RL: efficient training and rollout, including KV-cache management, request scheduling, and training-state
  placement; high-performance resumable sandboxes for long-horizon interaction
* AgentENV: microVMs with Firecracker; supports incremental checkpointing and resuming of sandbox states; OverlayBD
  image format; 51,219,741 sandboxes across 1,505,678 images were created
* inference: KDA-aware prefix cache packs the fixed-size recurrent state into the same paged pool as the MLA KV cache
  and keeps long prefixes reusable across requests
